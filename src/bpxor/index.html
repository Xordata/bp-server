Личная модель (13 + 2×лекарств → H(tanh) → H2(tanh) → 2, онлайн-обучение)

Фичи: час дня (sin/cos), день недели (sin/cos), барометр, температура, влажность, Kp, эмоция, шум, часы и качество сна, кол-во лекарств + на каждое лекарство две PK-фичи: остаточная активность (затухание по T½ от каждого приёма) и положение в окне действия. При изменении списка лекарств модель переучивается автоматически.

Уведомления

адрес: —

Push приходит даже с закрытой вкладкой (звук — системный, кастомный mp3 браузер в фоне воспроизвести не может). На iPhone — только если «Дневник» добавлен на домашний экран. Таймзона сервера: — (сообщается браузером автоматически).

Список лекарств

НазваниеT½, чДействие, чРасписание приёмаОтметка

T½ — период полувыведения, «Действие» — длительность действия (часы). Для известных препаратов подставлены справочные значения (medpk.json), для неизвестных — 8/12 ч; всё можно править. НН использует эти параметры: «остаточная активность» и «окно действия» каждого лекарства. «Расписание приёма» (через запятую, HH:MM) — балюн-напоминание в трее. Список нечувствителен к регистру.

Отметки приёма

«✓ Принять» отмечает фактический приём — НН строит PK-признаки по отметкам, даже когда лекарство не отмечено на измерении.

Справочник ФК (medpk.json)

НазваниеT½, чДействие, ч

Хранится в medpk.json рядом с программой — правится без пересборки (или редактированием файла). Используется, когда у лекарства нет персонального переопределения в таблице выше.

Общее

Пользователь

Модель использует их как признаки «возраст» (на момент каждого измерения) и «пол»; после изменения модель переобучается автоматически.

Норма и оповещение

Автозапуск (реестр HKCU\...\Run) применяется сразу, «Сохранить» не нужен.

HomeAssistant (опционально)

Если указан entity_id датчика — его значение перекрывает погоду из API.

Нейросеть

Новый размер слоя применится после «Сбросить модель» (вкладка «Модель»).
