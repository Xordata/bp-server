1. 概要と2つのインターフェース

電子式の血圧ダイアリー:測定値、体調ダイアリー、薬とアラーム。パーソナルなニューラルネットがあなたのデータから学習し、血圧の予測(天気・薬・睡眠不足への反応)を説明します。

💻 アプリ🌐 ウェブ bp.xor.world
動作場所あなたのコンピューター上。インターフェースはブラウザでアドレス localhost:8090 で開きます世界中どこからでも任意のブラウザで利用可能。メールとパスワードでログイン
データプログラムと同じフォルダに保存されますサーバーに保存され、1人1アカウントとなります
アラーム音Windows のシステム音。常に動作しますタブ内での再生 + ブラウザのプッシュ通知
特徴ポートの設定、ウェブとの同期デバイスとトークン、クイックカード「/q」、スマートフォンへのインストール

データは両方に同時に保持し、同期することができます(第12章)。

2. はじめ方

💻 アプリ

  1. インストーラー BpMonitorSetup.exe をダウンロードして起動してください(サイトでは「デバイス」セクションの「⬇ デスクトップ版」ボタン、または bp.xor.world の「⬇ デスクトップ版」)。再インストールしてもデータは変更されません。
  2. 起動するとトレイにアイコン ❤ が表示され、ブラウザでインターフェースが開きます。ブラウザが開かない場合は、トレイのアイコンをダブルクリックしてください。
  3. 「設定 → ユーザー」で生年月日と性別を入力してください — モデルはこれらを特徴量として使用します。
  4. 「設定 → 一般」で都市の座標を確認してください(天気情報に必要です)。

🌐 ウェブ

  1. https://bp.xor.world を開き、自分のメールでログインしてください(初回ログイン時にアカウントが自動作成されます。パスワードはあなたのメールのものです)。
  2. 続いて同じく「設定 → ユーザー」と座標を入力してください。

3. 血圧の測定

  1. 椅子に座り、腕をテーブルに置き、5分間安静にしてください。血圧計で測定します。
  2. ⚡ 測定(右上)を押します。時刻は現在のものが自動入力されます — 修正も可能です。
  3. 収縮期血圧(最高)・拡張期血圧(最低)と脈拍を入力します。飲んだ薬にチェックを入れ(飲んだ場合)、メモを追加してください。
  4. その時点の天気、地磁気状況、ダイアリーデータは自動的に取り込まれます。

🌐 ウェブ クイックカード /q(「⚡ クイック」ボタン)があります — 他の項目なしの3つの入力欄だけで、スマートフォンから便利です。

どの測定値も編集できます:「履歴」タブから開いてください — 編集内容は変更履歴として保存されます。

4. 履歴とグラフ

  • 履歴タブ — 測定値のテーブル(新しいものが上)とジャーナル。「さらに表示」ボタンで古い記録を追加読み込みします。
  • グラフ:時刻に対する血圧/脈拍、感情による点の塗り分け。日付フィルターはグラフの上にあります。
  • 「医師向けレポート」— 第13章を参照してください。

5. ダイアリー:感情、騒音、睡眠

3つの短い記録は、モデルが血圧の変化の理由を理解するのに役立ちます:

  • 感情 — −10(最悪)から +10(最高)まで;
  • 騒音/イベント — 妨げになったもの(コーヒー、ストレス、身体活動など);
  • 睡眠 — 時間と質(1〜10)。

測定のおよそ12時間以内(または測定後10分以内)に作成された記録は、自動的にその測定と関連付けられます。体調が悪い日だけでも記入してください — モデルが評価してくれます。

6. 薬

  • リスト — あなたが服用している薬剤。測定時にチェックボックスで表示され、モデルの予測に考慮されます(服用時刻と半減期が考慮されます)。
  • リマインダー — 薬剤ごとの服用時刻。トレイ(💻)またはプッシュ通知(🌐)でリマインダーが届きます。
  • 服用ジャーナル — 「✓ 服用」ボタンで実際の服用を記録します(測定のチェックボックスよりモデルに正確に伝わります)。
  • 薬物動態レファレンス — 薬剤ごとに半減期/作用持続時間を設定できます(デフォルトは医療レファレンスからの値)。

7. アラーム

アラームタブ — 行内で直接クイック編集できるリスト。モード:

  • 毎日 — 指定した時刻に;
  • 曜日指定 — 月〜日のチェックボックス;
  • N時間ごと — 例えば「8時間ごと」を有効化時点から。

「N分前に通知」— 事前に警告します。鳴動時にはメロディ alarm.mp3 が再生されます。停止はヘッダーの「⏹ 音」ボタン、またはトレイのアイコンをクリックしてください。

🌐 ウェブ タブが開いていればそのタブで鳴ります(1回だけ、他のタブと重複しません)。タブがなければプッシュ通知が届きます(第8章)。ブラウザがクリックなしでは音を許可しなかった場合は、ページ上で一度クリックしてください。

8. スマートフォン:ウェブアプリと通知 🌐

アプリとしてインストールする

  1. Chrome(Android)または Safari(iOS)で bp.xor.world を開いてログインします。
  2. 「設定 → デバイス → 📲 スマートフォンにインストール」(またはブラウザメニューの「アプリとしてインストール」/「ホーム画面に追加」)。
  3. インストール後、サイトはアドレスバーなしの通常のアプリとして開きます。

プッシュ通知を有効にする

  1. 「設定」の「通知」ブロックで 有効にする を押し、ブラウザの許可ダイアログを承認してください。
  2. ボタンはこのブラウザの状態を表示します。「📡 配信テスト」は登録済みデバイスすべてにテスト送信します。
  3. iPhone では、インストール済みの Safari-PWA からのみプッシュが動作します。

通知が届くケース:アラーム(開いているタブがない時)、薬のリマインダー、モデルからの警告。

9. ニューラルネットと予測

モデルタブ。ニューラルネットは次の要素からあなたの血圧を予測することを学習します:時刻、天気(気圧、気温、湿度、地磁気撹乱)、感情/騒音/睡眠、薬(服用時刻を考慮)、そして測定時点の性別と年齢。

  • 学習 — 通常の学習;遺伝的アルゴリズム — より入念な学習(バックグラウンドタスク、約30秒);自動選択 — モデルサイズの自動選択;検証 — 保留しておいた直近の測定による厳密な評価(MAE、mmHg 単位)と特徴量の「寄与度」。
  • データに重要な変更があるたびに(新しい測定、薬、天気)、自動的に再学習が行われます。
  • 予測 — モデルは時単位の天気予報に沿って実行され、あなたの基準値を外れるタイミングを表示します。同時に「約N時間後」という警告が届きます。
  • Kp アイコン — 地磁気撹乱の予測(≥5 は磁気嵐。敏感な人は血圧で反応します)。
モデルはアシスタントであり、診断ではありません。あなたのデータの法則性を説明しますが、医師の代わりにはなりません。

10. 天気と地磁気状況

ヘッダーの下に現在の天気と Kp が表示されます — これらは各測定に自動的に挿入されます(出典:アプリとサイトはノルウェー気象庁、Kp は GFZ/NOAA)。過去の日付で欠落した天気は後から補完できます:「モデル」タブ → 「天気を補完」(💻) — 測定日付に合わせてアーカイブが取得されます。

11. 設定

設定タブ — カード形式。「編集」で編集ウィンドウが開き、すべて即座に保存されます。

  • 基準値 — 収縮期/拡張期血圧のあなた自身の閾値(ハイライト、予測、レポートに使用)。
  • ユーザー — 名前、生年月日、性別(モデルに重要!)。
  • 一般 — 都市の座標、天気取得の間隔;💻 ウェブインターフェースのポート(変更には再起動が必要)。
  • 🌐 タイムゾーン — アラームとグラフ用。
  • 🌐 デバイス — アプリ/スクリプト用の同期トークン、スマートフォンへのインストールボタン、「⬇ デスクトップ版」。
  • 💻 同期 — 第12章。
  • モデル — ニューラルネットの詳細パラメータ(通常は変更不要)。

ダークテーマはシステム設定に応じて自動的に有効になります。

12. アプリとサイトの同期 💻↔🌐

コンピューターでもスマートフォンでも、手動での転送なしにダイアリーを続けるために:

  1. 🌐 サイトで:「設定 → デバイス → トークンを作成」。トークンをコピーします(1回だけ表示されます)。
  2. 💻 アプリで:「設定 → 同期」:有効にし、トークンを貼り付けて保存します。以降は1分ごと(または新しい測定の直後)に変更がサーバーへ送信され、逆方向にも受け取ります。
  3. 設定の「主」(どちらがもう一方に設定内容を渡すか:「デスクトップ」/「サーバー」/「同期しない」)もこのブロックで選択します。

ステータスは同じブロックに表示されます(「push +N / pull +N」)。「トークンが無効」というエラーの場合は、トークンを再作成してください。

13. エクスポート、医師向けレポート、バックアップ

  • 医師向けレポート(「履歴」→「医師向けレポート」、CSV または xlsx)— 日ごとのサマリー:測定、薬の服用、Kp、感情、騒音、睡眠。ファイルは Excel で開けます。
  • 全データのエクスポート — ダイアリー全体を1つの JSON ファイルに(別のコンピューターへの移行用:新しい場所で「インポート」)。インポート前に自動バックアップスナップショットが作成されます。
  • 💻 アプリは日次バックアップをプログラムと同じフォルダの backups\ に自動保存します(直近30日間)。
  • 🌐 サーバーのデータはサイト管理者がバックアップコピーを保持します。

14. よくある質問

アラームが2回鳴った / 鳴らなかった
2回鳴る場合 — 複数のタブやアプリが同時に開いていないか確認してください(タブ同士は協調しますが、アプリは独自に鳴らします)。スマートフォンで鳴らない場合 — 最初のクリックまでブラウザが音を許可していません:タブを開いてクリックしてください。プッシュはタブが閉じていて購読が有効な場合にのみ届きます(設定の「📡 配信テスト」)。
プッシュが届かない
「設定 → 通知」→「有効にする」→ 許可ダイアログを承認。スマートフォンが空なのに「有効にする」の代わりに「無効にする」ボタンが表示される場合?ページを更新してください — ボタンは現在のブラウザに対するものになりました。iOS では Safari + ホーム画面へのインストールのみ対応。
天気が測定に挿入されなかった
設定の座標とインターネット接続を確認してください。過去の測定には「天気を補完」を使用してください。
同期に「タスクがキャンセルされました」と表示される
サーバーと接続できません(またはプロキシ/VPN が妨げています)。このコンピューターのブラウザで bp.xor.world が開くか確認し、次のサイクルを待ってください — ステータスが更新されます。
パスワードを忘れた(ウェブ)
パスワードはあなたのメールのものです(メールサーバーが認証を兼ねています)。パスワードのリセットはメールサービスの機能で行ってください。
私のデータはどこにある?
💻 BpMonitor.exe と同じフォルダ(data\)にあり、あなたが同期を有効にしない限りどこにも送信されません。🌐 サーバー bp.xor.world にあり、アクセスはあなたのアカウントでのみ可能です。
