1. 这是什么以及两种界面

电子血压日记：测量记录、健康日记、药物和提醒。个人神经网络会在您的数据上学习，并解释血压预测（对天气、药物、睡眠不足的反应）。

💻 应用程序🌐 网页 bp.xor.world
运行位置在您的电脑上，界面通过浏览器以地址 localhost:8090 打开在世界任何地方的任意浏览器中，用邮箱和密码登录
数据保存在程序旁边的文件夹中保存在服务器上，每人一个账户
提醒声音Windows 系统声音，始终可用标签页内声音 + 浏览器推送通知
特点端口设置、与网页同步设备与令牌、快速卡片「/q」、安装到手机

数据可以同时保存在两处并进行同步（第 12 节）。

2. 从何开始

💻 应用程序

  1. 下载安装程序 BpMonitorSetup.exe（网站上——「设备」一节中的「⬇ 桌面版」按钮，或在 bp.xor.world 上的「⬇ 桌面版」）并运行——重新安装不会动数据。
  2. 启动后系统托盘会出现图标 ❤，浏览器会打开界面。如果浏览器没有打开——双击托盘图标。
  3. 进入「设置 → 用户」，填写出生日期和性别——模型会将它们作为特征使用。
  4. 在「设置 → 常规」中检查所在城市坐标（天气功能需要）。

🌐 网页

  1. 打开 https://bp.xor.world，用您的邮箱登录（首次登录时自动创建账户；密码就是您邮箱的密码）。
  2. 接下来同样是「设置 → 用户」和城市坐标。

3. 测量血压

  1. 坐姿，手臂放在桌上，休息 5 分钟。用血压计测量。
  2. 点击 ⚡ 测量（右上方）。时间会自动填入当前时间——可以修改。
  3. 输入收缩压/舒张压和脉搏。勾选已服用的药物（如果服了），可添加备注。
  4. 该时间的天气、地磁状况和日记数据会自动带入。

🌐 网页 有快速卡片 /q（「⚡ 快速」按钮）——只有三个字段，没有别的东西，用手机很方便。

任何测量记录都可以编辑：从「历史」标签页打开它——修改会保留变更历史。

4. 历史与图表

  • 历史标签页——测量记录表（最新的在上面）和日志。「显示更多」按钮加载较早的记录。
  • 图表：血压/脉搏随时间变化，按情绪着色。日期过滤器在图表上方。
  • 「给医生的报告」——见第 13 节。

5. 日记：情绪、干扰、睡眠

三条简短记录帮助模型理解血压变化的原因：

  • 情绪 — 从 −10（很糟）到 +10（很好）；
  • 干扰/事件 — 什么影响了您（咖啡、压力、体力活动……）；
  • 睡眠 — 小时数和质量（1–10）。

在测量前约 12 小时内（或测量后 10 分钟内）做出的记录会自动与之关联。至少在不舒服的日子填写——模型会因此更准确。

6. 药物

  • 列表 — 您正在服用的药品。它们在测量时以复选框显示，并参与模型预测（会考虑服药时间和半衰期）。
  • 服药提醒 — 每种药的服药时间；会在托盘（💻）或推送（🌐）中收到提醒。
  • 服药日志 — 「✓ 已服用」按钮记录实际服药事实（对模型而言比测量旁的复选框更精确）。
  • 药代动力学手册 — 可为每种药设置半衰期/作用时长（默认取自医学手册）。

7. 提醒

提醒标签页——列表可直接在行内快速编辑。模式：

  • 每天 — 在指定时间；
  • 按星期几 — 勾选周一至周日；
  • 每 N 小时 — 例如从启用时刻起「每 8 小时」。

「提前 N 分钟提醒」——提前预警。触发时刻会播放铃声 alarm.mp3；停止方法是点击页眉中的「⏹ 声音」按钮或点击托盘图标。

🌐 网页 如果有打开的标签页——它会在该标签页响铃（只响一次，不与其他标签页重复）。如果没有打开的标签页——会收到推送通知（第 8 节）。如果浏览器在未点击时不允许播放声音——只需在页面上点击一次即可。

8. 手机：Web 应用与通知 🌐

安装为应用

  1. 在 Chrome（Android）或 Safari（iOS）中打开 bp.xor.world 并登录。
  2. 「设置 → 设备 → 📲 安装到手机」（或浏览器菜单中的「安装应用」/「添加到主屏幕」）。
  3. 安装后网站会像普通应用一样打开，没有地址栏。

启用推送通知

  1. 在「设置」的「通知」区块中点击 启用 并允许浏览器弹出的请求。
  2. 按钮显示的是当前这个浏览器的状态；「📡 投递测试」会向所有已订阅设备发送测试消息。
  3. 在 iPhone 上，推送仅从已安装的 Safari-PWA 中有效。

通知会在以下情况送达：提醒（当没有打开的标签页时）、服药提醒、模型的预警。

9. 神经网络与预测

模型标签页。神经网络学习根据以下因素预测您的血压：一天中的时间、天气（气压、温度、湿度、地磁扰动）、情绪/干扰/睡眠、药物（考虑服药时间），以及测量时刻的性别和年龄。

  • 训练 — 常规训练；遗传 — 更精细（后台任务，约半分钟）；调优 — 自动选择模型规模；检验 — 在留出的最近测量上做公正评估（MAE，单位 mmHg）以及各特征的「贡献」。
  • 任何重要的数据变化（新测量、药物、天气）之后，会自动进行增量训练。
  • 预测 — 模型逐小时套用天气预报运行，显示预计何时会超出您的正常范围；同时会发出「约 N 小时后」的预警。
  • Kp 图标 — 地磁扰动预报（≥5 为磁暴，敏感人群会以血压波动作出反应）。
模型是助手，不是诊断。它解释您数据中的规律，但不能替代医生。

10. 天气与地磁状况

页眉下方显示当前天气和 Kp——它们会自动填入每条测量记录（数据来源：应用程序和网站使用挪威气象服务，Kp 使用 GFZ/NOAA）。过去几天缺失的天气可以补全：「模型」标签页 →「补齐天气」（💻）——历史数据会按测量日期自动拉取。

11. 设置

设置标签页——以卡片呈现；「修改」打开编辑窗口，所有内容即时保存。

  • 正常范围 — 您的收缩压/舒张压阈值（用于高亮、预测和报告）。
  • 用户 — 姓名、出生日期、性别（对模型很重要！）。
  • 常规 — 城市坐标、天气查询周期；💻 Web 界面端口（更改需重启）。
  • 🌐 时区 — 用于提醒和图表。
  • 🌐 设备 — 供应用/脚本使用的同步令牌、安装到手机的按钮、「⬇ 桌面版」。
  • 💻 同步 — 第 12 节。
  • 模型 — 神经网络的精细参数（通常无需更改）。

深色主题会随系统自动启用。

12. 应用程序与网站同步 💻↔🌐

要在电脑和手机上同时记日记而无需手动搬运数据：

  1. 🌐 在网站上：「设置 → 设备 → 创建令牌」。复制令牌（只显示一次）。
  2. 💻 在应用中：「设置 → 同步」：启用、粘贴令牌、保存。之后每分钟一次（或新测量后立即）变更会上传到服务器并回传。
  3. 谁是「主」（谁向谁下发配置）也在该区块中选择：「桌面」/「服务器」/「不同步」。

状态在同一区块中显示（「push +N / pull +N」）。出现「令牌无效」错误——请重新创建令牌。

13. 导出、给医生的报告、备份

  • 给医生的报告（「历史」→「给医生的报告」，CSV 或 xlsx）——按日的汇总：测量、服药、Kp、情绪、干扰、睡眠。文件可在 Excel 中打开。
  • 导出全部数据 — 一个包含整个日记的 JSON 文件（用于迁移到另一台电脑：在新位置使用「导入」）。导入前会自动做备份快照。
  • 💻 应用会自动在程序旁边的 backups\ 文件夹中保存每日备份（最近 30 天）。
  • 🌐 服务器数据由网站管理员进行备份。

14. 常见问题

提醒响了两遍 / 没有响
响两遍——检查是否同时打开了多个标签页和应用程序（标签页之间会协调，应用会自己响）。手机上没响——浏览器在首次点击前不允许播放声音：打开标签页并点击一下；推送只有在标签页全部关闭且已启用订阅时才会送达（设置中的「📡 投递测试」）。
推送不送达
「设置 → 通知」→「启用」→ 允许浏览器请求。手机是空的却显示「停用」而不是「启用」按钮？刷新页面——按钮现在对应的是当前浏览器。在 iOS 上——仅支持 Safari + 安装到「主屏幕」。
测量中没有带入天气
检查设置中的坐标和网络连接。对于较早的测量——使用「补齐天气」。
同步提示「任务已取消」
与服务器无连接（或代理/VPN 干扰）。先确认这台电脑的浏览器能否打开 bp.xor.world，然后等待下一个周期——状态会更新。
忘记密码（网页）
密码就是您邮箱的密码（邮件服务器本身就是验证）。重置密码请使用您邮箱的重置功能。
我的数据在哪里？
💻 在 BpMonitor.exe 旁边的文件夹（data\）中，除了您自己启用的同步外不会发送到任何地方。🌐 在 bp.xor.world 服务器上，只有您的账户可以访问。
