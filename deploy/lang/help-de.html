1. Was das ist und die zwei Oberflächen

Elektronisches Blutdruck-Tagebuch: Messungen, Befindlichkeits-Tagebuch, Medikamente und Erinnerungen. Ein persönliches neuronales Modell lernt aus Ihren Daten und erklärt die Blutdruckprognose (Reaktion auf Wetter, Medikamente, Schlafmangel).

💻 Anwendung🌐 Web bp.xor.world
Wo es läuftauf Ihrem Computer, die Oberfläche öffnet sich im Browser unter der Adresse localhost:8090in jedem Browser von überall, Anmeldung per E-Mail und Passwort
Datenwerden in einem Ordner neben dem Programm gespeichertwerden auf dem Server gespeichert, ein Konto pro Person
ErinnerungssoundSystemton von Windows, funktioniert immerTon im Tab + Push-Benachrichtigungen des Browsers
BesonderheitenPort-Einstellung, Synchronisation mit dem WebGeräte und Tokens, Schnellkarte „/q“, Installation auf dem Telefon

Die Daten können gleichzeitig an beiden Orten gehalten und synchronisiert werden (Abschnitt 12).

2. Womit anfangen

💻 Anwendung

  1. Laden Sie das Installationsprogramm BpMonitorSetup.exe herunter (auf der Website — die Schaltfläche „⬇ Desktop-Version“ im Abschnitt „Geräte“ bzw. „⬇ Desktop-Version“ auf bp.xor.world) und starten Sie es — bei einer Neuinstallation werden die Daten nicht angetastet.
  2. Nach dem Start erscheint im Tray ein Symbol ❤, und im Browser öffnet sich die Oberfläche. Falls sich der Browser nicht geöffnet hat — doppeltes Klicken auf das Symbol im Tray.
  3. Gehen Sie zu „Einstellungen → Benutzer“ und geben Sie Geburtsdatum und Geschlecht an — das Modell nutzt sie als Merkmale.
  4. Prüfen Sie unter „Einstellungen → Allgemein“ die Koordinaten Ihrer Stadt (für das Wetter erforderlich).

🌐 Web

  1. Öffnen Sie https://bp.xor.world und melden Sie sich mit Ihrer E-Mail an (das Konto wird beim ersten Login automatisch erstellt; das Passwort ist das Ihrer E-Mail).
  2. Danach folgen dieselben Schritte: „Einstellungen → Benutzer“ und die Koordinaten.

3. Blutdruck messen

  1. Im Sitzen, Arm auf dem Tisch, 5 Minuten ausruhen. Mit dem Tonometer messen.
  2. Klicken Sie auf ⚡ Messung (oben rechts). Die Zeit wird automatisch eingetragen — sie kann korrigiert werden.
  3. Geben Sie systolischen/diastolischen Wert und Puls ein. Markieren Sie die eingenommenen Medikamente (falls welche genommen wurden) und fügen Sie eine Notiz hinzu.
  4. Wetter, geomagnetische Lage und Tagebuchdaten für diesen Zeitraum werden automatisch übernommen.

🌐 Web Es gibt eine Schnellkarte /q (Schaltfläche „⚡ schnell“) — drei Felder ohne alles Weitere, praktisch vom Telefon aus.

Jede Messung kann nachträglich bearbeitet werden: öffnen Sie sie im Tab „Verlauf“ — die Bearbeitung speichert die Änderungshistorie.

4. Verlauf und Diagramme

  • Der Tab Verlauf — eine Tabelle der Messungen (neueste oben) und ein Protokoll. Die Schaltfläche „Mehr anzeigen“ lädt ältere Einträge nach.
  • Diagramme: Blutdruck/Puls über die Zeit, punktwweise Einfärbung nach Emotionen. Datumsfilter — über dem Diagramm.
  • „Arztbericht“ — siehe Abschnitt 13.

5. Tagebuch: Emotionen, Lärm, Schlaf

Drei kurze Einträge helfen dem Modell zu verstehen, warum sich der Blutdruck verändert hat:

  • Emotion — von −10 (furchtbar) bis +10 (hervorragend);
  • Lärm/Ereignisse — was gestört hat (Kaffee, Stress, körperliche Belastung…);
  • Schlaf — Stunden und Qualität (1–10).

Ein Eintrag, der innerhalb von ~12 Stunden vor der Messung (oder innerhalb von 10 Minuten danach) gemacht wurde, wird automatisch mit ihr verknüpft. Füllen Sie sie zumindest an Tagen mit schlechtem Befinden aus — das Modell wird es Ihnen danken.

6. Medikamente

  • Liste — die Präparate, die Sie einnehmen. Sie werden bei der Messung als Checkboxen angezeigt und fließen in die Prognose des Modells ein (Einnahmezeitpunkt und Halbwertszeit werden berücksichtigt).
  • Erinnerungen — Einnahmezeiten für jedes Präparat; im Tray (💻) oder per Push (🌐) kommt eine Erinnerung.
  • Einnahmeprotokoll — die Schaltfläche „✓ Einnehmen“ erfasst den tatsächlichen Einnahmefakt (für das Modell genauer als die Checkbox bei der Messung).
  • PK-Referenz — für jedes Präparat können Halbwertszeit/Wirkdauer festgelegt werden (standardmäßig aus der medizinischen Referenz).

7. Erinnerungen

Der Tab Erinnerungen — eine Liste mit schneller Bearbeitung direkt in der Zeile. Modi:

  • jeden Tag — zur angegebenen Zeit;
  • nach Wochentagen — Häkchen Mo–So;
  • alle N Stunden — zum Beispiel „alle 8 Stunden“ ab dem Zeitpunkt der Aktivierung.

„N Min. vorher erinnern“ — eine Vorwarnung. Zum Auslösezeitpunkt spielt die Melodie alarm.mp3; stoppen — über die Schaltfläche „⏹ Ton“ in der Kopfzeile oder durch Klick auf das Symbol im Tray.

🌐 Web Falls ein Tab geöffnet ist — läutet er (einmal, ohne Duplizierung mit anderen Tabs). Falls keine Tabs offen sind — kommt eine Push-Benachrichtigung (Abschnitt 8). Falls der Browser ohne Klick keinen Ton abspielt — klicken Sie einfach einmal auf der Seite.

8. Telefon: Web-App und Benachrichtigungen 🌐

Als App installieren

  1. Öffnen Sie bp.xor.world in Chrome (Android) oder Safari (iOS) und melden Sie sich an.
  2. „Einstellungen → Geräte → 📲 Auf dem Telefon installieren“ (oder im Browsermenü „App installieren“ / „Zum Startbildschirm“).
  3. Nach der Installation öffnet sich die Website wie eine normale App, ohne Adressleiste.

Push-Benachrichtigungen aktivieren

  1. Klicken Sie in den „Einstellungen“ im Block „Benachrichtigungen“ auf Aktivieren und erlauben Sie die Browseranfrage.
  2. Die Schaltfläche zeigt den Zustand genau dieses Browsers an; „📡 Zustelltest“ schickt einen Testversuch an alle abonnierten Geräte.
  3. Auf dem iPhone funktioniert Push nur aus der installierten Safari-PWA.

Benachrichtigungen kommen für: Erinnerungen (wenn keine offenen Tabs existieren), Medikamentenerinnerungen und Warnungen des Modells.

9. Neuronales Modell und Prognose

Der Tab Modell. Das neuronale Modell lernt, Ihren Blutdruck vorherzusagen anhand von: Tageszeit, Wetter (Luftdruck, Temperatur, Luftfeuchtigkeit, geomagnetische Störungen), Emotionen/Lärm/Schlaf, Medikamenten (unter Berücksichtigung der Einnahmezeit) sowie Geschlecht und Alter zum Messzeitpunkt.

  • Trainieren — normales Training; Genetik — gründlicher (Hintergrundaufgabe, ~eine halbe Minute); Anpassen — automatische Wahl der Modellgröße; Prüfen — ehrliche Bewertung auf zurückgehaltenen letzten Messungen (MAE in mmHg) und „Beitrag“ der Merkmale.
  • Nach jeder wesentlichen Änderung der Daten (neue Messung, Medikament, Wetter) erfolgt ein Nachtraining automatisch.
  • Prognose — das Modell wird über den stündlichen Wetterbericht laufen gelassen und zeigt, wann eine Überschreitung Ihrer Norm erwartet wird; dann kommt auch die Warnung „in ~N Stunden“.
  • Das Symbol Kp — die Prognose geomagnetischer Störungen (≥5 — Magnetstürme, Sensible reagieren mit Blutdruckänderungen).
Das Modell ist ein Assistent, keine Diagnose. Es erklärt Gesetzmäßigkeiten Ihrer Daten, ersetzt aber keinen Arzt.

10. Wetter und geomagnetische Lage

Unter der Kopfzeile werden das aktuelle Wetter und Kp angezeigt — sie werden automatisch in jede Messung eingetragen (Quelle — der norwegische Wetterdienst für Anwendung und Website, GFZ/NOAA — für Kp). Fehlendes Wetter der vergangenen Tage kann nachgetragen werden: Tab „Modell“ → „Wetter nachziehen“ (💻) — das Archiv wird anhand der Messdaten-Daten nachgeladen.

11. Einstellungen

Der Tab Einstellungen — Karten; „Bearbeiten“ öffnet ein Bearbeitungsfenster, alles wird sofort gespeichert.

  • Norm — Ihre Schwellenwerte für systolischen/diastolischen Wert (für Hervorhebungen, Prognosen und den Bericht).
  • Benutzer — Name, Geburtsdatum, Geschlecht (wichtig für das Modell!).
  • Allgemein — Koordinaten der Stadt, Abfrageintervall des Wetters; 💻 Port der Web-Oberfläche (eine Änderung erfordert einen Neustart).
  • 🌐 Zeitzone — für Erinnerungen und Diagramme.
  • 🌐 Geräte — Synchronisations-Tokens für Anwendung/Skripte, Schaltfläche zur Installation auf dem Telefon, „⬇ Desktop-Version“.
  • 💻 Synchronisation — Abschnitt 12.
  • Modell — Feinparameter des neuronalen Modells (normalerweise nicht zu ändern).

Dunkles Design wird automatisch nach den Systemeinstellungen aktiviert.

12. Synchronisation der Anwendung mit der Website 💻↔🌐

Um das Tagebuch sowohl auf dem Computer als auch auf dem Telefon zu führen, ohne manuell zu übertragen:

  1. 🌐 Auf der Website: „Einstellungen → Geräte → Token erstellen“. Kopieren Sie das Token (es wird nur einmal angezeigt).
  2. 💻 In der Anwendung: „Einstellungen → Synchronisation“: aktivieren, Token einfügen, speichern. Danach gehen die Änderungen einmal pro Minute (oder sofort nach einer neuen Messung) an den Server und kommen zurück.
  3. Wer in den Einstellungen „führend“ ist (wem die Konfiguration diktiert wird) — wird ebenfalls in diesem Block gewählt: „Desktop“ / „Server“ / „nicht synchronisieren“.

Der Status ist in demselben Block sichtbar („push +N / pull +N“). Fehler „ungültiges Token“ — erstellen Sie das Token neu.

13. Export, Arztbericht, Sicherungskopien

  • Arztbericht („Verlauf“ → „Arztbericht“, CSV oder xlsx) — eine Tagesübersicht: Messungen, Medikamenteneinnahme, Kp, Emotionen, Lärm, Schlaf. Die Datei öffnet sich in Excel.
  • Export aller Daten — eine JSON-Datei mit dem gesamten Tagebuch (für die Übertragung auf einen anderen Computer: „Import“ am neuen Ort). Vor dem Import wird automatisch eine Sicherungskopie erstellt.
  • 💻 Die Anwendung speichert selbst tägliche Backups im Ordner backups\ neben dem Programm (die letzten 30 Tage).
  • 🌐 Die Serverdaten werden vom Website-Administrator sicherungskopiert.

14. Häufige Fragen

Die Erinnerung ertönte zweimal / gar nicht
Zweimal — prüfen Sie, ob nicht mehrere Tabs und die Anwendung gleichzeitig geöffnet sind (die Tabs stimmen sich untereinander ab, die Anwendung läutet selbst). Kein Ton auf dem Telefon — der Browser erlaubte den Ton vor dem ersten Klick nicht: öffnen Sie den Tab und klicken Sie; Push kommt nur, wenn die Tabs geschlossen sind und das Abonnement aktiv ist („📡 Zustelltest“ in den Einstellungen).
Push kommt nicht
„Einstellungen → Benachrichtigungen“ → „Aktivieren“ → erlauben Sie die Anfrage. Die Schaltfläche zeigt „Deaktivieren“ statt „Aktivieren“ bei leerem Telefon? Laden Sie die Seite neu — die Schaltfläche bezieht sich jetzt auf den aktuellen Browser. Auf iOS — nur Safari + Installation auf den Startbildschirm „Home“.
Wetter wurde nicht in die Messung eingetragen
Prüfen Sie die Koordinaten in den Einstellungen und den Internetzugang. Für ältere Messungen — „Wetter nachziehen“.
Die Synchronisation meldet „Aufgabe abgebrochen“
Keine Verbindung zum Server (oder ein Proxy/VPN stört). Prüfen Sie, ob bp.xor.world im Browser auf diesem Computer geöffnet wird, und warten Sie dann den nächsten Zyklus ab — der Status aktualisiert sich.
Passwort vergessen (Web)
Das Passwort ist das Ihrer E-Mail (der Mailserver ist die Prüfung). Passwortzurücksetzung — über die Mittel Ihres E-Mail-Anbieters.
Wo sind meine Daten?
💻 im Ordner neben BpMonitor.exe (data\), sie werden nirgendwohin gesendet, außer bei von Ihnen aktivierter Synchronisation. 🌐 auf dem Server bp.xor.world, Zugriff — nur unter Ihrem Konto.
